Podratic builds collaboration software for engineering teams.

## Pogo

[Pogo](https://pogo.podratic.com) is our flagship product. Teams use it in the browser to run the sessions they already
hold:

- **Planning poker.** Estimate work together in a live session.
- **Retrospective boards.** Reflect on how a piece of work went.
- **Developer experience surveys.** Track what it is like to build in your team.
